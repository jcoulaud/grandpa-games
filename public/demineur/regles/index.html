Comment jouer au démineur sans deviner ?

Ouvrez toutes les cases sans mine. Chaque chiffre vous donne un indice sur les huit cases qui l’entourent.

Que veulent dire les chiffres ?

Un 1 indique qu’une mine touche la case. Un 2 indique qu’il y en a deux. Comptez aussi les cases en diagonale.

Le premier clic est sans danger sur Jeux de Papi. Cliquez sur une case pour l’ouvrir. Utilisez le bouton « Poser un drapeau », ou le clic droit, pour marquer une mine.

Un 1 et une seule case fermée

Regardez toutes les voisines du 1. Si elles sont toutes ouvertes sauf une, la mine est dans la dernière case fermée.

Un 1 touche déjà un drapeau

Si le drapeau est bien placé, vous avez déjà trouvé la mine du 1. Les autres cases fermées qui touchent ce 1 sont sûres.

Deux chiffres peuvent partager des voisines

Comparez les cases fermées que touchent deux chiffres. Si le 2 touche les mêmes cases que le 1, plus une seule autre, cette autre case cache une mine.

Essayez le niveau facile

Le niveau facile vous montre les cases sûres et les mines que vous pouvez déduire. Il vous aide à repérer ces motifs quand ils apparaissent au milieu d’une vraie grille.

Quand vous voulez trouver le prochain coup par vous-même, passez au niveau moyen. Le jeu propose des grilles que vous pouvez résoudre sans deviner.
