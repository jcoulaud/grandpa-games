Règles du code secret : deviner la combinaison de couleurs

L’ordinateur cache quelques pions de couleur. À vous de trouver lesquels, et dans quel ordre, grâce à ses réponses.

Trouver le code secret

L’ordinateur cache une rangée de pions de couleur sous un couvercle : quatre pions aux niveaux Facile et Moyen, cinq au niveau Difficile. Vous devez retrouver les couleurs et leur ordre.

À chaque essai, cliquez sur des couleurs pour remplir une colonne, puis sur « Valider ». L’ordinateur répond par de petites fiches. Le couvercle s’ouvre quand vous trouvez le code ou quand les essais sont finis.

Lire les fiches noires et blanches

Une fiche noire pleine veut dire : une bonne couleur à la bonne place. Un anneau blanc veut dire : une bonne couleur, mais à une autre place. L’ordinateur ne dit pas quels pions sont concernés : c’est à vous de le déduire.

Les couleurs en double

Aux niveaux Moyen et Difficile, une couleur peut revenir plusieurs fois dans le code et dans vos essais. Chaque pion du code ne donne qu’une seule fiche.

Choisir son niveau

Les trois niveaux
NiveauPions à trouverCouleursEssais
Facile4, toutes différentes612
Moyen4, une couleur peut revenir610
Difficile5, une couleur peut revenir810

Au niveau Facile, une couleur déjà posée dans la colonne porte une coche dans la réserve. Il y a 360 codes possibles au niveau Facile, 1 296 au niveau Moyen et 32 768 au niveau Difficile.

Une méthode simple pour trouver le code

  1. Commencez par des couleurs différentes : la réponse vous dit combien d’entre elles sont dans le code.
  2. Changez une seule chose à la fois, par exemple deux pions qui échangent leur place. Comparez la nouvelle réponse avec la précédente.
  3. Gardez ce qui fait monter le nombre de fiches noires.

Un clic sur une colonne déjà jouée relit son essai et sa réponse dans la ligne du haut.

Utiliser l’aide et annuler

Le bouton « Que jouer maintenant ? » pose une combinaison qui respecte toutes les réponses déjà reçues, et dit combien de codes restent possibles. Avec cette aide, l’ordinateur trouve le code en 4 essais en moyenne au niveau Facile, et en 5 à 6 essais au niveau Difficile.

« Annuler le dernier coup » retire le dernier pion posé. Si la colonne est vide, il reprend l’essai précédent. Une partie finie ne s’annule pas, puisque le code a été montré.
