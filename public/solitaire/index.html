Solitaire

Déplacer une carte

Cliquez sur une carte visible. Si elle a une seule place, elle y va toute seule. Si plusieurs places sont encadrées en jaune, choisissez-en une.

Déplacez une suite d'un seul coup. Seul un roi peut commencer une colonne vide.

Ranger les cartes pour gagner

Rangez toutes les cartes sur les quatre piles « Rangement », en haut à droite.

Dans les colonnes, une carte cachée se retourne dès que vous la libérez.

Utiliser la pioche

Si la pioche est vide, cliquez dessus pour la retourner.

Si vous hésitez, cliquez sur « Que jouer maintenant ? ». Pour reprendre un coup, cliquez sur « Annuler le dernier coup ».
